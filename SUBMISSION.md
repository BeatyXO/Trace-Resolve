# Submission Copy

## Name

Trace Resolve

## Short description

Trace Resolve is a pink GenLayer loading spinner where the three sections of the GenLayer mark subtly align, then a pale pink-white highlight travels through the resolved logo before the cycle releases and repeats.

## Concept

The design keeps the GenLayer mark itself as the dominant loading identity. Instead of placing a large orbit, ring, or decorative object around the logo, the motion happens almost entirely within the mark.

The three geometric pieces begin only a few pixels apart and resolve into their canonical positions. Once aligned, a high-contrast pink-white trace sweeps across the logo. The mark then releases into the next loop.

## Why it fits the Portal

- original animated SVG
- smooth infinite 1.65s loop
- GenLayer mark remains dominant
- pink/magenta identity
- same asset works on light, neutral and dark backgrounds
- tested from 16px through 64px
- no JavaScript runtime needed
- reduced-motion support
- React and CSS implementations included
- live loading-state examples included
