# Start Here

## If you are the repository owner

1. Rename the repository if needed.
2. Use the published links in the project documentation.
3. Run `npm test`.
4. Open `docs/index.html` locally and visually inspect the spinner.
5. Commit and push.
6. Enable GitHub Pages from `main /docs`.
7. Verify both live URLs.
8. Use `SUBMISSION.md` for the task submission.

## If you are a coding agent

Use the project documentation and run `npm test` before submission.
